# Valor Mortis — полевой путеводитель

**Русский** · [English](./README.en.md)

**Сайт:** [alexsuslin.com/valor-mortis-cheatsheet](https://alexsuslin.com/valor-mortis-cheatsheet/) · **Репозиторий:** [alexsuslin/valor-mortis-cheatsheet](https://github.com/alexsuslin/valor-mortis-cheatsheet)

Интерактивный помощник для прохождения Valor Mortis по образцу [Hell Is Us checklist](https://github.com/alexsuslin/hellisus-cheatsheet). Маршрут, важные решения, текущий шаг, снаряжение и достижения в одном месте.

## Возможности

- 152 действия в 11 главах и 61 разделе локаций и возвращений.
- 20 заданий; для одного явно отмечено неполное описание завершения.
- 39 достижений с выбором Steam, PS5 или Xbox и ручной отметкой открытия.
- Вкладки «Сейчас», «Прохождение», «Достижения», «Мой билд», «Советы».
- 12 этапов билда, девять отметок снаряжения и девять напоминаний.
- RU/EN, светлая и тёмная темы, поиск, фильтры и скрытие выполненного.
- Локальное сохранение, экспорт/импорт JSON, перенос ссылкой и QR-кодом.

**Есть спойлеры:** сюжет, боссы, задания и находки. Русский текст — удобный перевод; английские названия сохранены для поиска и сверки с игрой.

## Полнота

Релизное издание проверено по источникам 14 октября 2026 года. Это не утверждение о лично проверенном прохождении на 100%. Счётчик учитывает включённые действия, а не уникальные предметы. Некоторые этапы объединяют несколько взаимодействий; иллюстрированные подробности доступны по ссылке на источник.

В разделе «Источники и полнота» вынесены шесть уточнений: число янтарей, неизвестный дубликат Glass Soldier, неполное завершение «Мама и папа», точный момент ограничения перемещения, возможный дополнительный флакон Верных Клятве и изменения сундуков после патча. Неизвестные находки не превращаются в невыполнимые галочки.

Предупреждения различают риск достижения, провал задания, потерю награды и временное ограничение доступа. [Исследование и ссылки](./docs/research.md) сохраняют исходные выводы и противоречия.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Откройте **http://127.0.0.1:4174/**. Не открывайте HTML двойным щелчком: браузер ограничивает загрузку модулей и JSON через файловую систему.

```sh
npm test
npm run check
npm run build
npm run test:browser
```

В Windows браузерные тесты используют установленный Edge. В Linux/macOS сначала выполните `npx playwright install chromium`. Тестовый сервер использует порт 4181.

Проверка готовой сборки с префиксом репозитория:

```sh
node scripts/serve.mjs --dist --subpath
```

Адрес: **http://127.0.0.1:4174/valor-mortis-cheatsheet/**. Предварительно остановите другой сервер на порту 4174 либо задайте свободный порт через переменную `PORT`.

## Сохранение

Данные находятся в браузере под отдельным ключом `valor-mortis-checklist-v1`. Прогресс Hell Is Us не затрагивается. Отметка получения оружия в маршруте может отметить получение в билде, но улучшение и экипировка остаются ручными. Снятие галочки маршрута не удаляет уже полученное снаряжение.

Экспортируйте JSON перед очисткой браузера. Импорт сначала показывает число записей и требует подтверждения замены. Отмена, повреждённый файл и сохранение другой игры не меняют текущий прогресс. Сброс также требует подтверждения.

«Перенос / QR» создаёт снимок прогресса. Часть ссылки после `#` не отправляется серверу при загрузке; QR-код создаётся локально. Любой обладатель ссылки может прочитать снимок. Автоматической синхронизации нет: после новых отметок создавайте новую ссылку. Получатель сначала видит предварительный просмотр, затем применяет замену.

Другой браузер, устройство, адрес или порт использует отдельное хранилище. Для переноса нужен экспорт или ссылка. Если браузер запретил запись, не закрывайте вкладку и экспортируйте оставшийся в памяти прогресс.

## Публикация и разработка

`npm run build` создаёт статические файлы в [dist/](./dist/). [GitHub Actions](./.github/workflows/check.yml) проверяет форматирование, данные и поведение в браузере, затем публикует сборку на GitHub Pages. Отправка изменений в `main` автоматически обновляет сайт; другие ветки и pull request проходят проверки без публикации. Используется существующий домен аккаунта `alexsuslin.com`; отдельные изменения DNS и CNAME для проекта не нужны.

Данные находятся в [data/](./data/). Не меняйте постоянный ID при правке формулировки. Позиции [каталога переноса](./assets/transfer-catalog.js) можно только дополнять: перестановка повредит старые ссылки. Подробные правила сопровождения и лицензии описаны в [английской документации](./README.en.md).
